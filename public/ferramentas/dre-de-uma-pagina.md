# DRE de uma página — o modelo para mandar ao seu contador

> Copie o texto abaixo e mande para o seu contador. Ele já tem esses números; o que falta é o
> formato. DRE de quatro páginas ninguém lê, e o que ninguém lê não vira decisão.

## Mensagem pronta

*"Boa tarde. Preciso mudar o formato do relatório mensal. Em vez do DRE completo, me manda esse
resumo de uma página, com o mês fechado e o mesmo mês do ano passado lado a lado. Pode continuar
gerando o completo para os fins contábeis — esse aqui é para eu decidir."*

## O formato

| Linha | Mês | % da receita | Mesmo mês ano passado |
|---|---|---|---|
| Receita bruta | | 100% | |
| (−) Impostos sobre venda | | | |
| (−) Devoluções e cancelamentos | | | |
| **= Receita líquida** | | | |
| (−) Custo direto (material + mão de obra da execução) | | | |
| **= Margem de contribuição** | | | |
| (−) Folha administrativa e comercial | | | |
| (−) Pró-labore | | | |
| (−) Ocupação (aluguel, energia, condomínio) | | | |
| (−) Veículos | | | |
| (−) Serviços de terceiros (contador, software, jurídico) | | | |
| (−) Comercial e marketing | | | |
| (−) Outras despesas | | | |
| **= Resultado operacional** | | | |
| (−) Juros e tarifas bancárias | | | |
| (−) Depreciação | | | |
| **= Resultado líquido** | | | |

## As três linhas que você lê primeiro

1. **Margem de contribuição %** — se cair dois meses seguidos, o problema é preço ou custo direto,
   e nenhum corte de despesa fixa resolve.
2. **Resultado operacional** — é o lucro do negócio funcionando. Se estiver negativo com a receita
   crescendo, você está vendendo prejuízo em escala.
3. **A coluna do ano passado** — sem comparação, todo número parece razoável.

## O que NÃO pedir

Não peça mais detalhe. A tentação é abrir cada linha em dez subcontas, e aí o relatório volta a
ter quatro páginas e você volta a não ler. Detalhe se pede quando uma linha específica chama
atenção, e só naquela linha, naquele mês.
